# DDM_hydrodynamic
The main goal is to predict the spatiotemporal behavior of velocity u(x,t) using pressure p(x,t) data based on methods:

Data-driven methods (DMD, SINDY)

Machine learning algorithms


# Methods used
Data-Driven Techniques:

DMD, DMDс, SINDY

Machine Learning Approaches:

LSTM, 2D Fourier Neural Operator, Implicit Adaptive Fourier Neural Operator, U-Net
